# ttrnkv — сайт-портфолио Данилы Татарникова

Сайт: https://danlmrr.github.io

## Как добавить картинки (код трогать не нужно)

Загрузи файл с нужным именем в нужную папку — он сам появится на сайте:

| Что | Куда и с каким именем |
|---|---|
| Обложка кейса на главной и в кейсе | `cases/img/<кейс>/cover.jpg` |
| Картинки внутри кейса | `cases/img/<кейс>/1.jpg` … `6.jpg` |
| Твоё фото в «Кто я» | `assets/img/me.jpg` |
| Обложки видео | `assets/img/video-showreel.jpg`, `video-sketch.jpg`, `video-truecrime.jpg` |

`<кейс>` — это `case-1`, `case-2`, `case-3`, `avk`, `case-5`.

На GitHub: открой папку → **Add file → Upload files** → перетащи файл → **Commit changes**.
Через 1–2 минуты сайт обновится.

## Что ещё заменить (ищи слово ЗАМЕНИ)

- `assets/main.js` — ник в Telegram (`TG_NICK`), одно место на весь сайт.
- `index.html` — цены `[от … ₽]`, ссылки на видео в `data-video`.
- `cases/*.html` — тексты кейсов в `[квадратных скобках]`.
