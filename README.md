# ttrnkv — сайт-портфолио Данилы Татарникова

Сайт: https://danlmrr.github.io (русский) · https://danlmrr.github.io/en/ (английский)

## Картинки и звук — просто загрузи файл с нужным именем

| Что | Куда и с каким именем |
|---|---|
| Обложка кейса (главная и страница кейса) | `cases/img/<кейс>/cover.jpg` |
| Картинки внутри кейса | `cases/img/<кейс>/1.jpg` … `6.jpg` |
| Твоё фото в «Обо мне» | `assets/img/me.jpg` |
| Обложки вертикальных видео | `assets/img/v-1.jpg` … `v-4.jpg` |
| Обложки горизонтальных видео | `assets/img/h-1.jpg`, `h-2.jpg` |
| Видеоотзывы-кружки (обложка) | `assets/img/r-1.jpg` … `r-4.jpg` |
| Голосовые отзывы | `assets/audio/voice-1.mp3` … `voice-3.mp3` |

`<кейс>` — это `case-1`, `case-2`, `case-3`, `avk`, `case-5`. Один файл работает сразу на русской и английской версии.

На GitHub: открой папку → **Add file → Upload files** → перетащи файл → **Commit changes**. Через 1–2 минуты сайт обновится.
